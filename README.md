# Streetcar Scenes 1–3

A study website for *A Streetcar Named Desire*, Scenes 1–3, read through the psychoanalytic lens. It goes with our 7-minute class presentation.

**Live site:** https://mathpaglu.github.io/Street-car-presentation/

## What's on the site

- **The lens in 60 seconds:** id, ego and superego, with Stanley, Stella and Blanche
- **Exposition** and the argument in one line
- **Key quotations** from Scenes 1–2, each with its lecture timestamp
- **The Poker Night:** Stella vs Stanley, and Blanche and Mitch
- **Learning from professors:** six learnings, with evidence from the lecture videos, the professors' slides and the play
- **Comparison with *Persepolis***
- **Practise:** quote flashcards and a 10-question quiz
- **Glossary** of psychoanalytic terms
- **Present it in 7 minutes:** a rehearsal timer and the script for every slide
- **Works cited**

## How it works

The whole site is one file, `index.html`, with no build step. GitHub Pages publishes it from the `gh-pages` branch: edit `index.html` on that branch and commit, and the live site updates within a minute or two.
